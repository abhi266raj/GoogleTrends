# Distribution

Both products compile the same Sources/TrendingHashtag files. TrendingHashtag is a dynamic XCFramework for universal macOS, iPhone and iOS Simulator. TrendingHashtagSource is the portable source product. GoogleTrends and GoogleTrendsSource are retained as backward-compatible product aliases. Choose one product per dependency graph. Build with Scripts/build-xcframework.sh before resolving a development checkout. Semantic release tags download a checksummed binary automatically.
